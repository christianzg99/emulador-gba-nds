# Emulador GBA y NDS

Emulador web de Game Boy Advance y Nintendo DS. Las ROMs se cargan desde tu dispositivo y no se suben a ningún sitio.

- GBA, GB y GBC: motor mGBA
- NDS: DeSmuME (rápido) o melonDS (preciso)

Construido sobre [EmulatorJS](https://github.com/EmulatorJS/EmulatorJS) (GPL-3.0); los motores son núcleos libretro de código abierto. No incluye ROMs: usa copias de tus propios juegos.
