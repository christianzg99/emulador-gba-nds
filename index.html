Ayuda
  • Usa copias de tus propios juegos. Emulador Zeta no incluye ninguno.
  • Cada juego que abres se queda en tu biblioteca. Desde ⋯ ves cuánto ocupa y puedes quitarlo; su partida guardada se conserva.
  • Durante la partida, ☰ abre el menú: guardado rápido, velocidad, turbo, imagen, trucos, capturas y la posición de los botones.
  • Con un mando Bluetooth los botones de la pantalla se ocultan solos. Select + Start abre el menú.
  • En ordenador: flechas para moverte, Z y X para B y A, Intro para Start y Mayúsculas para Select.
